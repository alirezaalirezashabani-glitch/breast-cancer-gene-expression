
# Breast Cancer Gene Expression Analysis

## Overview
This project focuses on the bioinformatics analysis of apoptosis-related genes in breast cancer.

## Research Objectives
- Investigate apoptosis-associated genes in breast cancer.
- Explore the expression patterns of BAX, BCL2, CASP3, and TP53.
- Identify potential molecular relationships relevant to cancer biology.

## Genes of Interest
- BAX
- BCL2
- CASP3
- TP53

## Research Background
This project is inspired by experimental research on breast cancer cells (MCF-7) and the effects of beta-cyclocitral and nanoparticle-based treatments.

## Planned Analyses
- Public gene expression dataset analysis
- Data visualization
- Differential gene expression
- Apoptosis pathway interpretation
